## 📌 Acerca de este Repositorio (`romeca`)

Este repositorio reúne la **estrategia profesional, certificaciones, plantillas metodológicas y artefactos de gestión** de Rosmar Mendoza orientados al rol de **Technical Project Manager / Agile Delivery Lead**.

A diferencia de un portafolio tradicional de desarrollo de software, este repositorio demuestra **criterio técnico aplicado a la gestión de proyectos, mitigación de riesgos de release, observabilidad de producción y metodologías ágiles avanzadas**.
